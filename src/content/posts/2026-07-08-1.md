> 在网络安全与渗透测试的学习过程中，一个安全、可控的本地实验环境是必不可少的。**Pikachu（皮卡丘）** 是一款非常优秀的、国内开源的 Web 漏洞练习平台，涵盖了绝大多数常见的 OWASP Top 10 漏洞。
> 本文将详细演示如何利用 **小皮面板（phpStudy）** 在 Windows 环境下从零开始快速搭建起属于你自己的个人专属靶场。

---

## 一、 环境准备与必备组件

在开始搭建之前，我们需要准备好靶场运行所必需的集成环境和源码。本次搭建主要使用以下两个核心组件：

1. **小皮面板 (phpStudy)**：提供 Apache Web 服务器、MySQL 数据库以及 PHP 解析环境。
   - [小皮面板官网下载地址](https://www.xp.cn/phpstudy)
   
2. **Pikachu 靶场源码**：GitHub 开源的漏洞练习平台项目。
   - [GitHub - zhuifengshaonianhanlu/pikachu 源码仓库](https://github.com/zhuifengshaonianhanlu/pikachu)

> 💡 **避坑小贴士**：
> 本地搭建的靶场中含有大量真实漏洞（如文件上传、命令执行等），**切勿将靶场端口映射至外网或公网服务器**，以免被恶意攻击者利用作为跳板。建议严格在本地（Localhost / 局域网）环境内进行测试。

---

## 二、 靶场详细搭建步骤

### 1. 安装并运行小皮面板

首先从官网下载并安装最新版的小皮面板（phpStudy）。安装完成后将其打开，主界面提供了非常直观的图形化管理后台。

### 2. 启动核心服务

在小皮面板的“首页”或者“软件管理”中，找到 **Apache** 和 **MySQL** 两个核心服务，点击右侧的 **“启动”** 按钮。当状态指示灯变为蓝色时，说明本地的 Web 环境和数据库已成功运行。

![成功启动 Apache 与 MySQL 服务](https://tu.223333333.xyz/file/2026-07-12-images/1787811859183_2026-07-08-1.avif)

### 3. 部署靶场源码至 Web 根目录

进入小皮面板的安装路径，找到其默认的 Web 根目录 **`WWW`** 文件夹。将原本的默认初始化文件清空，接着从 GitHub 下载得到的 `pikachu-master` 源码压缩包完整解压，并将其整个文件夹拖入到 `WWW` 目录中。

![将 pikachu-master 源码部署至 WWW 根目录](https://tu.223333333.xyz/file/2026-07-12-images/1787811856418_2026-07-08-2.avif)

### 4. 修改数据库连接配置文件

为了让靶场源码能够顺利连接上小皮面板自带的 MySQL 数据库，我们需要手动校对并配置数据库密码。

打开解压出来的源码目录，定位到 `phpstudy_pro/WWW/pikachu-master/inc/config.inc.php` 文件，使用代码编辑器将其打开。找到以下数据库参数段，**根据你小皮面板数据库中的实际密码进行修改**（小皮面板默认的用户名和密码通常均为 `root`）：

```php
define('DBHOST', '127.0.0.1'); // 数据库服务器地址
define('DBUSER', 'root');      // 数据库用户名
define('DBPW', 'root');        // 将此处修改为连接 MySQL 的正确密码
define('DBNAME', 'pikachu');   // 靶场数据库名（建议保持默认）
define('DBPORT', '3306');      // MySQL 连接端口
```

### 5. 获取本地局域网 IP 地址

为了方便从多端或者标准地址进行访问，我们需要获取本机的本地 IP。按下键盘上的 `Win + R` 键，输入 `cmd` 打开终端命令行。在其中输入：

<pre><code>ipconfig</code></pre>

在输出的结果中，找到你当前正在连网的 **“无线局域网适配器 WLAN”**，记录下其中的 **`IPv4 地址`**（例如：`192.168.1.40`）。

![通过 cmd 命令行执行 ipconfig 获取本机 IPv4 地址](https://tu.223333333.xyz/file/2026-07-12-images/1787811864863_2026-07-08-3.avif)

### 6. 访问并完成靶场系统初始化

打开浏览器，在地址栏中按照以下格式输入你的靶场初始化访问路径：`http://你的IP地址/pikachu-master/install.php`（例如：`http://192.168.1.40/pikachu-master/install.php`）。

进入页面后，点击正中间的 **“安装/初始化”** 按钮。

> ⚠️ **注意**：这一步一定要确保**第 4 步中的数据库密码修改完全正确**，否则此步会报错提示无法连接数据库。

![进入 install.php 页面成功点击安装初始化](https://tu.223333333.xyz/file/2026-07-12-images/1787811857702_2026-07-08-4.avif)

### 7. 开启漏洞演练

当系统提示“数据库连接成功、新建数据库成功”后，点击页面的提示链接返回首页，或者直接访问 `http://你的IP地址/pikachu-master/`。

至此，Pikachu 漏洞练习平台已彻底搭建完成！你现在可以点击左侧的导航栏，开始愉快地研究暴力破解、SQL 注入、XSS 等经典漏洞的利用与防御了。

### 8. 返回主目录完成收尾

确认所有功能可以正常访问后，返回 `你的ip地址/pikachu-master` 根目录。至此，完整的本地个人渗透测试演练场已经全部就绪。

![靶场完全搭建成功返回主目录](https://tu.223333333.xyz/file/2026-07-12-images/1787811865192_2026-07-08-5.avif)
